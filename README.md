# Pixel Divers Website

The official landing page for Pixel Divers, a 2D co-op ocean survival adventure. Live at [pixeldivers.world](https://pixeldivers.world).

## Structure

- `index.html` - the landing page (single file, no build step)
- `eula/index.html` - the End User License Agreement, served at `/eula`
- `assets/` - logo, panorama background, custom cursor, banner, and the Pixel Explorers font
- `CNAME` - custom domain config for GitHub Pages

## Hosting

Served by GitHub Pages from the `main` branch root. Pushing to `main` deploys automatically.
